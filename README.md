# 🎬 AI 视频总结

粘贴视频网页地址（B站、新闻网站等）或上传本地视频/音频文件，自动生成结构化总结。

## 功能

- ✅ **网页视频**：B站、YouTube 及 yt-dlp 支持的各类网站；普通网页里的嵌入视频（B站/YouTube iframe、mp4/m3u8 直链）也能自动识别
- ✅ **本地文件**：拖拽上传 mp4 / mkv / mov 等视频，或 mp3 / wav / m4a 等音频
- ✅ **字幕优先**：视频自带字幕（含 B站 AI 字幕、本地内嵌字幕）直接提取，秒级完成
- ✅ **云端转写**：无字幕时音轨上传硅基流动 Qwen3-ASR 转写，极快（实测 3.5 分钟音频仅 4 秒），费用约几毛钱/小时
- ✅ **智能总结**：DeepSeek 生成结构化总结（一句话概括 / 核心要点带时间点 / 关键结论 / 金句），支持自定义要求（如"用英文总结"）
- ✅ **实时进度**：界面上按「获取视频 → 提取音轨 → 语音转写 → 生成总结 → 保存结果」分步显示状态和进度条；下载/转码进度来自 ffmpeg 与 yt-dlp 的真实数据，自带字幕的步骤显示「跳过」
- ✅ **结果可下载**：总结（`.md`）和完整转录稿（`.txt`，含时间标记）都能从结果区直接下载

## 快速开始

1. **注册硅基流动**：打开 [cloud.siliconflow.cn](https://cloud.siliconflow.cn)，注册后进入「API 密钥」创建 Key（新用户有免费额度，充值 ¥10 可转写数十小时视频）
2. **双击 `start.bat`**：首次运行自动创建环境并安装依赖（2-3 分钟），之后自动打开浏览器
3. **粘贴 API Key → 保存**，然后粘贴视频网址或拖入本地文件 → 点「🚀 开始总结」

## 使用说明

| 场景 | 操作 |
|------|------|
| B站/YouTube 视频 | 复制视频页网址，粘贴到「视频网页地址」 |
| 普通网页里的视频 | 直接粘贴网页地址，工具会尝试从源码中找视频 |
| 本地视频 | 把文件拖到「本地视频 / 音频文件」区域 |
| 自定义输出 | 在「额外总结要求」写要求，如：`用英文总结`、`300 字以内`、`重点讲最后 30 分钟` |

结果区实时显示各步骤进度，完成后展示最终总结（Markdown）。下方的两个卡片分别下载**总结 `.md`** 和**完整转录稿 `.txt`**（含时间标记，方便回看原文出处）。

## 工作原理

```
网页视频 ──yt-dlp──→ 优先提取自带字幕 ──┐
                                       ├→ 文字稿 ──DeepSeek──→ 结构化总结
本地文件 ──ffmpeg──→ 内嵌字幕 / 音轨 ───┘
                         │
              无字幕 → 音轨切分(10分钟/段) → Qwen3-ASR 云端转写
```

## 常见问题

- **B站视频提示需要登录？** 浏览器装「Get cookies.txt LOCALLY」扩展导出 cookies，存为项目目录下 `cookies.txt` 即可
- **YouTube 访问失败？** 需要代理。在命令行先执行 `set HTTPS_PROXY=http://127.0.0.1:端口` 再运行 `start.bat`（或在系统代理开启时直接使用）
- **转写结果为空？** 检查 API Key 余额，或该视频几乎没有语音内容
- **模型失效？** 工具会自动换用账号可用的最新 DeepSeek 模型；也可在设置里手动填模型名
- **速度与费用参考**：转写速度约为音频时长的 1/50（1 小时视频约 1 分钟转完），按音频时长计费约几毛钱/小时；总结按字数计费，每次几分钱。总结模型默认 DeepSeek-V4-Flash（快），可在设置里换成 V4-Pro（质量更高、稍慢）
- **隐私**：API Key 和转写音轨会上传到硅基流动服务器处理；敏感本地视频建议自行评估
- **更新依赖**：`.venv\Scripts\pip install -U yt-dlp gradio`（yt-dlp 需要定期更新以适配网站变化）

## 文件说明

| 文件 | 作用 |
|------|------|
| `app.py` | Web 界面 |
| `summarizer.py` | 核心流程（提取 / 转写 / 总结） |
| `start.bat` | 一键启动 |
| `config.json` | API Key 等配置（首次保存后生成，**已加入 `.gitignore`，请勿外传**） |
| `config.example.json` | 配置文件模板（供参考，字段说明见下） |
| `输出/` | 成品：转录稿 `.txt` + 总结 `.md`，永久保留（已忽略，不会提交） |
| `work/` | 临时文件（中间音频用完即删，跑完自动清空） |
| `cookies.txt` | 可选，B站等网站的登录态（**已加入 `.gitignore`，请勿外传**） |

> 💡 `config.json` 不是必需的：界面里保存 API Key 时会自动生成。想手动配置，可以复制 `config.example.json` 为 `config.json` 再填写。
